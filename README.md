## 1. Project Overview

**SentiPulse** is an enterprise-grade AI-powered public health intelligence and syndromic surveillance platform. It monitors public, permitted, and anonymized social media discussions (from Reddit, public health forums, and authorized syndromic data streams) to detect unusual surges in disease symptoms days before clinical PCR confirmations or hospital emergency room surges occur.

### Key Capabilities:
- **SentiPulse Intelligence Assistant**: An intelligent, conversational public-health pair programmer integrated both as a dedicated full-page command center and a global floating assistant. Answers complex questions including disease dominance by area, multi-regional risk comparison, anomaly mathematics, intervention protocols, and real-time alert triage.
- **Privacy-Preserving Natural Language Processing**: Automated regex-based pseudonymization stripping usernames (`@handle`), URLs, emails, and phone numbers. Contextual negation analysis ("no fever", "tested negative") and idiom/noise filtering ("spring fever", "cough up cash").
- **Statistical Outbreak Forecasting**: Rolling 14-day baseline computation ($\mu, \sigma$), statistical Z-score anomaly thresholding, and multi-horizon forecasts (7, 14, 30 days) equipped with 80% and 95% uncertainty confidence intervals.
- **Interactive Geospatial Surveillance Map**: OpenStreetMap Leaflet visualization color-coding regional risk tiers (Low, Moderate, High, Critical) with clear distinction between social signals and verified clinic cases.
- **Early Warning & Alert Triage Hub**: Configurable anomaly sensitivity threshold slider, trigger explainability breakdowns, and public health response protocols.
- **Reports & Export Center**: Real-time CSV data exporter and printable, PDF-ready executive summaries for health ministries and epidemiological teams.
- **Role-Based Demonstration Authentication**: Four pre-configured operational personas (Public Health Officer, Chief Epidemiologist, Surveillance Researcher, Public Viewer) with an interactive access matrix.

## 3. Mathematical & Prediction Methodology

### 3.1 Rolling Statistical Baseline & Anomaly Z-Score
For a given region or symptom category across time series $x_1, x_2, \dots, x_t$, the system computes rolling baseline statistics over a sliding window $W = 14$ days:

$$\mu_t = \frac{1}{W} \sum_{i=t-W}^{t-1} x_i, \qquad \sigma_t = \sqrt{\frac{1}{W-1} \sum_{i=t-W}^{t-1} (x_i - \mu_t)^2}$$

The current anomaly Z-score is given by:

$$Z_t = \frac{x_t - \mu_t}{\sigma_t}$$

- **Normal Baseline**: $Z_t < 1.0\sigma$
- **Elevated Discussion**: $1.0\sigma \le Z_t < 2.0\sigma$
- **High Anomaly**: $2.0\sigma \le Z_t < 3.0\sigma$
- **Critical Spike**: $Z_t \ge 3.0\sigma$

### 3.2 Probabilistic Outbreak Risk Score
The composite outbreak probability integrates four weighted components:

$$L_t = w_z \cdot \tilde{Z}_t + w_v \cdot \Delta \tilde{v}_t + w_s \cdot \tilde{S}_{\text{syndromic}} + w_r \cdot \tilde{R}_{\text{divergence}}$$

Where:
- $w_z = 0.38$: Statistical Z-score deviation above baseline
- $w_v = 0.28$: 7-day discussion growth velocity ($\Delta v$)
- $w_s = 0.22$: Syndromic clinical severity index (multi-symptom co-occurrence)
- $w_r = 0.12$: Divergence ratio against expected seasonal norms ($x_t / \mu_t$)

The calibrated probability is generated via a logistic sigmoid activation function:

$$P(\text{outbreak}) = \frac{100}{1 + \exp\left(-k \cdot (L_t - x_0)\right)}$$

- **Low Risk**: $P < 35\%$
- **Moderate Risk**: $35\% \le P < 60\%$
- **High Risk**: $60\% \le P < 80\%$
- **Critical Risk**: $P \ge 80\%$

### 3.3 Multi-Horizon Forecasting & Uncertainty Cones
Future trajectories for horizons $h \in \{7, 14, 30\}$ days are projected using damped trend extrapolation:

$$\hat{x}_{t+h} = x_t + \sum_{j=1}^{h} \phi^j \cdot v_t$$

Where $\phi = 0.88$ is the damping parameter and $v_t$ is recent velocity. The uncertainty variance expands with time horizon $\sqrt{h}$:

$$\text{CI}_{80}(h) = \hat{x}_{t+h} \pm 1.28 \cdot \sigma \sqrt{0.4 \cdot h}, \qquad \text{CI}_{95}(h) = \hat{x}_{t+h} \pm 1.96 \cdot \sigma \sqrt{0.4 \cdot h}$$

## 5. Quick Start Guide

### Prerequisites
- **Node.js** (v18.0+ recommended) and `npm`
- **Python** (3.9+ recommended)

### Step 1: Start the Python REST Backend
Open a terminal in the project root:
```bash
cd backend
python server.py
```
*The server will start listening on `http://localhost:8000` with zero pip dependencies required.*

*(Optional)* If you have FastAPI and Uvicorn installed:
```bash
cd backend
pip install -r requirements.txt
uvicorn fastapi_app:app --host 0.0.0.0 --port 8000 --reload
```

### Step 2: Start the Frontend Application
In a second terminal:
```bash
npm install
npm run dev
```
Open your browser and navigate to:
**`http://localhost:5173/`**

### Step 3: Run Backend Unit Tests
To verify NLP classification, negation detection, prediction logic, and the AI agent:
```bash
cd backend
python -m unittest discover -s tests
```
*Result: 13 tests run in ~0.005s, 100% passing.*

## 8. Responsible AI & Public Health Ethics

- **Zero PII Retention**: User handles (`@user`), URLs, emails, and phone numbers are redacted immediately upon ingestion using strict regular expressions.
- **Non-Clinical Stance**: The system does not diagnose individuals or prescribe medical treatments. It evaluates aggregated syndromic trends across populations.
- **Verification Gate**: Automatically generated alerts are marked as *Unverified Public Health Signals* until validated through official laboratory testing (such as CDC ILINet or WHO FluNet).
- **Proportional Response**: Restrictive public health interventions must never be triggered solely from social media signals without independent verification.
